YouTube Music

Writes your Daily and Weekly playlists to YouTube Music. Playing tracks in Digger doesn't need it.

Reads your YouTube Music login from Chrome on this Mac, no developer tools. When macOS asks to use “Chrome Safe Storage”, click Allow (not Always Allow). Connect is the by-hand way.

  1. Open music.youtube.com in your browser while signed in.
  2. Open developer tools (⌥⌘I / F12) and go to Network.
  3. Type browse in the filter, then click around the site until a request shows up.
  4. Click a POST request to music.youtube.com and find its Request Headers.
  5. Copy them: right-click the request → Copy → Copy as cURL (Chrome, Brave, Edge), or Copy Value → Copy Request Headers (Firefox). Selecting the Request Headers section by hand works too.
  6. Paste below and log in. The headers go straight to the server and are never shown again.
